# 腾讯元宝 · 福利中心每日任务自动完成（iOS / TrollStore 巨魔版）

在 **iPhone 本机**里跑，不连电脑、不用数据线、不用代理。
原理：用巨魔（TrollStore）/ TrollFools 把一个 `.dylib` 插件注入元宝 App，
插件在元宝进程内用系统自带 **Vision 中文 OCR** + **视图树文字搜索** 找按钮并触发，
完成福利中心 6 项任务。

> 和「安卓 Termux 版」最大的区别：**没有写死坐标**。
> 按钮靠文字定位，元宝改版 / 换机型一般都不用改代码；
> 实在找不到，用面板里的「点文字录制」对准按钮点一下，它就把那串文字记成锚点。

---

## 一、需要什么

| 项 | 要求 |
|---|---|
| 设备 | 已越狱的 iPhone，或装了 **TrollStore（巨魔）** 的 A11 及以下 / 已支持机型 |
| 注器 | **TrollFools**（推荐，免重签，直接给已装 App 注入 dylib） |
| 元宝 App | App Store 官方最新版 |
| 系统 | iOS 14+（Vision 中文 OCR 需要 14+） |
| 电脑 | 仅 **编译阶段** 需要（没 mac 可用 GitHub Actions，见下） |

> 本插件**不依赖 substrate / ellekit**，只用 `__attribute__((constructor))` 自启动，
> 所以任何注入方式（TrollFools / 重签名注入 / 越狱插件）都能跑。

---

## 二、编译出 .dylib（两步）

代码在 `src/`（就是本目录的 `.m/.h`）。两种方式二选一：

### 方式 A：本地有 theos 工具链

```bash
export THEOS=~/theos
./build.sh
# 产物：build/YuanbaoCheckin.dylib
```

### 方式 B：没有 mac / 没有 theos（推荐）

把本目录推到 GitHub，仓库自带的 Actions 会自动编好：
`.github/workflows/build.yml` → 跑完后在 **Actions → Artifacts** 下载
`YuanbaoCheckin-dylib`。

## 三、注入到元宝（TrollFools，1 分钟）

1. 手机装 **TrollFools**（TrollStore 里装）。
2. 把 `YuanbaoCheckin.dylib` 传到手机（AirDrop / 微信文件助手 / iCloud 均可）。
3. 打开 TrollFools → 选择 **元宝** → **注入** → 选那个 dylib。
4. **冷启动**元宝（从后台彻底划掉再打开）。

打开元宝后：
- 右下角出现蓝色悬浮球「元宝」→ 点开是控制面板。
- 面板里可 **立即执行全部任务**、勾选要跑的任务、设置每天自动时间、看实时日志。

---

## 四、怎么用

### 第一次：校准（只做一次）

1. 进元宝 → 打开一次 **福利中心**，确认能正常进入。
2. 点悬浮球 → **▶ 立即执行全部任务**，看日志跑到哪一步。
3. 如果某一步日志写「未找到 XXX」：
   - 点 **🎯 点文字录制** → 屏幕变半透明 → **对准那个按钮点一下**；
   - 弹出列表里选它属于哪一步（例如 `ask.entry`），以后这一步就用这串文字定位。
4. 再跑一次，直到 6 项都过。

### 日常

- 面板里设好时间（默认 **00:05**）。**iOS 进程不常驻**，所以有两条路保证跑：
  1. 到点若元宝在前台/后台仍在，定时器触发；
  2. **打开元宝就自动补做**（默认开）：今天没跑过的话，进 App 约 6 秒后自动开始。
- 跑完会在 `Documents/` 留一份 `YuanbaoCheckin-<时间>.json` 报告（在 TrollFools 的
  沙盒文件浏览里能看到）。

### 任务代号

| 代号 | 面上叫 | 做什么 |
|---|---|---|
| `checkin` | 能力站 / 签到 | 点第 1 天卡片并领奖 |
| `ask` | 趣问元宝得积分 | 用推荐问题真实发一条 |
| `write` | 使用写作能力 | 输入话题并发送 |
| `photo` | 使用拍题能力 | 相册选图 → 提交 |
| `pimage` | 使用P图能力 | 选图 → 发送 → 等出图 |
| `tpl` | 使用推荐模板做同款 | 去体验 → 模板广场 → 做同款 → 生成 |

## 五、跑不动怎么办

| 现象 | 原因 | 处理 |
|---|---|---|
| 没有悬浮球 | dylib 没注入 / 启动的不是元宝 | TrollFools 里确认已注入该 App；冷启动元宝；看设备日志 `[YB]` 前缀 |
| 日志「当前不是元宝进程」 | bundle id 不匹配 | 在 `Tweak.m` 的 `kYBBundleIDs()` 里加上正确 id |
| OCR 一个字都没有 | Vision 中文语言未就绪 | 系统设置 → 通用 → 语言与地区，确保「中文（简体）」在列；重启 App |
| `未找到 xxx`（某一步） | 界面改版 / 文字不同 | 用「点文字录制」对准该按钮点一下并绑定到对应 slot |
| 点了没反应 | 命中视图但不触发 | 该按钮可能是自绘/WebView；优先用「点文字录制」；必要时在 `YBTouch.m` 扩展触发方式 |
| 相册页点不中 | 相册是**系统进程**，插件看不到它的视图 | 本插件靠 OCR 点第一张；若失败，改用录制锚定「最近项目」等文字 |
| 到点没跑 | iOS 后台限制 | 依赖「打开元宝自动补做」；或每天手动点一次「立即执行」 |
| 半路被切后台中断 | 后台任务到期 | 插件已申请 `beginBackgroundTask` 续跑，最多再撑约 30 秒；尽量别切走 |

### 改文字锚点（不改代码的方式）

面板 → 🎯 点文字录制 → 对准按钮 → 选 slot。记录会写进 `NSUserDefaults`，
下次运行优先生效。想恢复默认：删掉 App 的偏好设置，或（开发用）调 `[YBConfig resetAliases]`。

### 改代码里的默认锚点

所有默认文字在 `YBConfig.m` 顶部 `YBDefaultSlots()`，长这样：

```objc
@"write.entry": @[@"使用写作能力", @"去写作", @"写作", @"写文章"],
```

加词即可，命中任意一个就算找到。

## 六、目录里都是什么

```
Tweak.m         入口：constructor 注入 + 进程判定 + 开机自动补做
YBEngine.m/.h   流程编排：步骤机（找文字→点/输入→等）
YBTouch.m/.h    进程内点按：视图树找控件、UIControl/cell/手势三层触发
YBScreen.m/.h   进程内截图 + Vision 中文 OCR
YBConfig.m/.h   设置持久化 + 每个步骤的文字锚点 + 6 项任务定义
YBStep.m/.h     单步的抽象（tap / tapOCR / input / wait / sleep）
YBLog.m/.h      环形缓冲 + 落盘日志（面板实时看）
YBUI.m/.h       悬浮球 + 控制面板 + 「点文字录制」
build.sh        本地编译 dylib
.github/…       GitHub Actions：没有 mac 也能编
```

## 七、几句实话

- **依赖元宝当前界面**。文字锚点能抗大部分改版，但流程步骤（先点哪个再点哪个）
  变了就得改 `YBConfig.m` 的 `stepsForTask:`。日志会明确写卡在哪一步。
- **不用 root**，但要能注入 dylib（巨魔环境）。
- **iOS 没有“定时无人值守”这回事**。最稳的用法是：每天睡前打开一次元宝，
  它自动补做；或者干脆把元宝常驻后台 + 到点定时。
- 同一任务每天上限 3 次，重复跑不会多拿积分，所以补做很安全。
- 仅供个人学习与自动化研究，请遵守元宝的用户协议。
